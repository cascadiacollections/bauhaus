- Run the code for yourself, unchanged, including its name
- Use the name "Bauhaus" nominatively: to refer to this project in articles, reviews,
  compatibility notes ("based on Bauhaus"), and attribution

The generated images are licensed separately, per image; see [Licensing](README.md#licensing).

## Why

This is the standard FOSS arrangement (used by Firefox, VLC, and many others): the code is free,
the identity is not. It protects users from confusing or misleading clones without restricting
any freedom the license grants.
